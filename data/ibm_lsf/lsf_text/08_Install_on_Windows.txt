If you are installing LSF Express Edition, you can later upgrade to LSF Standard Edition to take advantage of the additional features of LSF Standard

You can also manually upgrade from LSF Express Edition to Standard Edition. Get the LSF Standard entitlement conﬁguration ﬁle

but you might need to change some of the default LSF Express Edition conﬁguration parameters to use the LSF Standard Edition features.
After LSF is installed and running, run the lsid command to see which edition of LSF is enabled.
Installing a new IBM Spectrum LSF cluster
Run the LSF installer to install the management host and to install other hosts.
Procedure
1. Install the management host.
a. Log on as the primary LSF administrator (DOMAIN\lsfadmin) to the management host (or use an installation account that belongs to
the Local Administrators group).
b. Run the installer (that is, the lsf<version>_win-x64.msi ﬁle) to create a new cluster.
After the management host installation is complete, the LSF installer creates a batch ﬁle (install.bat) that you can use to silently install hosts
in this cluster. The batch ﬁle sets the installation parameters and runs the installer.
You must customize this batch ﬁle for speciﬁc hosts (management candidates, LSF server hosts, and LSF client hosts) in the cluster before
installation.
2. Install other hosts.
a. Install management candidates.
b. Install LSF server hosts.
c. Install LSF client hosts.
3. If you disabled automatic startup of LSF after installation, log on to the management host as lsfadmin and run lsfstartup to start the cluster.
4. Test your cluster by running some basic LSF commands (for example, lsid, lshosts, bhosts).
